A third idiom, `and #mask,r0; shll2 r0; braf r0` into a run of `bra` stubs (no data table), is recognised too. Crazy Taxi: 42 of the 43 computed jumps recovered (the stub shape is also accepted, capped at 32 entries, when the index scaling sits in a predecessor's delay slot), +6,121 instructions reached, whole-binary compile unchanged; `p6_switch` covers the two table idioms. Extents may overlap (each copy emits its own blocks); branch-derived entries never trim or fragment their hosts. Blocks a walk reached but the extent trim left outside also become functions. Crazy Taxi: 3,498 functions (301 branch), **direct branches to untranslated addresses down from 65 to 0**, switch tables 42/42, +6% emitted instructions from the overlap (compile 13.4 s), 176 fault stubs for undefined words (116 before; the extra ones are branch targets inside data reached from sweep/pointer false positives). `discover` now lists `switch_sites` in its JSON. `bsrf` targets (literal + pc + 4) are call seeds (WP1.6 idiom pass). Entry FPSCR mode inferred per function from its callers (4 inferred, 166 ambiguous in Crazy Taxi) 2026-09-12: origins ranked (seed/call > pointer > sweep > branch) so a lower-confidence entry never trims a called function (Crazy Taxi's kmiFBgetfreememEx was eleven fragments; `ADXF_Close` was cut in a delay slot), delay-slot addresses rejected as seeds, functions ending in a conditional branch fall through, and every function has a resume entry for non-local returns (setjmp/longjmp task switches; `docs/emitter-design.md`).
